# Test vectors

QR / payload test vectors for exercising the seedmix scanner.

Everything here is generated by [`../../scripts/gen_vectors.py`](../../scripts/gen_vectors.py):

```
python scripts/gen_vectors.py
```

(Requires `segno` and `pillow`)

## Layout

### `psbt/`

Bitcoin PSBT vectors collected from Blockchain Commons
(BCR-2020-006 / keytool-cli; see `psbt.json` for source URLs).

| dir      | contents |
|----------|----------|
| `raw/`   | raw PSBT bytes: `<slug>.hex` and `<slug>.base64` |
| `ur/`    | Blockchain Commons URs: `<slug>.v2.ur` (`ur:psbt`), `<slug>.v1.ur` (`ur:crypto-psbt`), `<slug>.multipart.ur` (one `ur:psbt/N-M/...` part per line) |
| `qr-png/`| QR PNGs: `<slug>.v2.png`, `<slug>.v1.png`, and `<slug>.part-NN.png` for each multipart part |
| `qr-gif/`| `<slug>.multipart.gif` — animated QR cycling through the multipart parts |

### `seedqr/`

SeedQR vectors in the SeedSigner format (`docs/seed_qr/README.md`).

| dir      | contents |
|----------|----------|
| `raw/`   | `<slug>.compact.bin` (raw 16/32-byte entropy = CompactSeedQR), `<slug>.standard.txt` (48/96 BIP-39 index digits = Standard SeedQR), `<slug>.mnemonic.txt` (the mnemonic, for reference) |
| `qr-png/`| `<slug>.compact.png` and `<slug>.standard.png` |

`bip39_english.txt` is the BIP-39 English word list used to derive the
Standard SeedQR digit streams.

## C test suite

The payloads here are also consumed by the C unit tests at runtime:
`seedmix_ur_tests` decodes each PSBT's hex, v1/v2 UR and multipart parts, and
`seedmix_seedqr_tests` round-trips every SeedQR compact/standard vector against
the reference mnemonic. The vectors directory is passed in as
`TEST_VECTORS_DIR` (see `tests/CMakeLists.txt`), so regenerate with
`python scripts/gen_vectors.py` before running the tests.
